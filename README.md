## Selected Work

### DualDA — Dual-Space Generative Data Assimilation

A dual-space generative framework coupling latent-space analysis with state-space conditional diffusion for sparse atmospheric observations.

- First author, AAAI 2027 under review
- Built with Python, PyTorch, VAE, and conditional diffusion
- Achieved an overall nRMSE of 0.1178, approximately 4.5% lower than FNP

### GDP-KG — Global Pesticide Knowledge Graph

An end-to-end knowledge graph platform for pesticide information retrieval.

- Multi-source pesticide data collection and processing
- Knowledge graph construction and querying with Neo4j
- Web system development and deployment
- [Live Demo](https://gdpkg.samlab.cn/)
